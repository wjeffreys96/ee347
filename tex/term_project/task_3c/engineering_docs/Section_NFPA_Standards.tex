\paragraph{} For all NFPA 70 requirements the 2014 draft version was used.

\begin{itemize}
	\item Lockout/Tagout Procedure - Annex G {\newline} {\indent}
	      We followed the sequence of the lockout/tagout procedure as relevant.

	\item Conductor sizing - 310.15 {\newline} {\indent}
	      18 gauge wire was used in the panel according with table 310.15(B)(16).
	      This decision was based on an  expected expected maximum current
	      draw of 0.982A for this control system.
	      And is well under the maximum 14A that 18 gauge wire is allowed.
	      % 0.9(power supply)+16m(PLC)+16m(inputs)+10m(outputs)+40m(both lights)=982mA

	\item Ampacity factor - 210.19(A)(1) - 210.20(A) {\newline} {\indent}
	      Because this system will be operated as a continuous load the
	      ampacity of the conductors used is not less
	      than the noncontinuous load plus 125 percent of the continuous load.
	      The maximum allowable ampacity is 14A, while our load is 1.22A, which is well within range.
	      % 0.9(power supply)+16m(PLC)+16m(inputs)+10m(outputs)+40m(both lights)=982mA

	\item Fuse sizing - 240.6 {\newline} {\indent}
	      Based on the max expected current draw of 0.982A and the NFPA
	      paragraph listed we selected 1A fuses.

	\item Equipment grounding - 250.119 {\newline} {\indent}
	      All grounding wires are green in compliance with the paragraph listed.

	\item Conductor location use - 310.10(A) {\newline} {\indent}
	      All wires selected for this system are of type THHN. This wire is
	      acceptable for the dry conditions in which
	      our panel will operate.

	\item Adjustable-speed drive systems - 430.120 to 430.131 (Article 430, Part X) {\newline} {\indent}
	      Because the VFD controls the motor’s speed, this is the part of the code that covers it. The VFD was installed following these requirements as relevant.

	\item VFD input conductor sizing - 430.122 {\newline} {\indent}
	      The wires feeding the VFD must be rated for at least 125 percent of the VFD’s rated input current. The conductors used are well above that minimum at 18AWG, which
	      is good for 14A.

	\item Motor overload protection - 430.32 and 430.124  {\newline} {\indent}
	      The motor is protected by a thermal overload relay.

	\item Disconnecting means - 430.102 and 430.128 {\newline} {\indent}
	      The VFD and motor need a disconnect that can be locked open. The lockout/tagout panel serves this purpose.
\end{itemize}
